# Bundled diagram browser resources

Mermaid 11.12.0: unmodified official mermaid.min.js, MIT. All embedded third-party
license comments remain intact; full upstream LICENSE is beside the script.

@plantuml/core 1.2026.9: unmodified official TeaVM plantuml.js and viz-global.js,
MIT. Full upstream LICENSE is beside the scripts. The selected Viz.js 3.24.0
browser file embeds Graphviz 14.1.1 and Expat 2.7.3 object code. VIZ-LICENSE,
GRAPHVIZ-COPYING/GRAPHVIZ-EPL-1.0 and EXPAT-COPYING preserve the full applicable
notices/licenses, obtained from exact version/commit upstream sources.

PROVENANCE.json pins official npm archives by exact version, URL, length and
SHA512 and every selected file by size/SHA256. Supplementary notice sources
are pinned by URL/length/SHA256. files.sha256 is generated by the explicit
vendoring tool. No scripts/dependency installation run while vendoring, building
or rendering. No CLI, Node, Java or browser runtime is included.

The native helper's Guild license is shipped as HELPER-LICENSE. It uses the
system's AppKit/WebKit, with no downloaded browser. No JS is embedded in the
Rust executable. See tools/diagrams/renderer/README.md in the Guild repository.
